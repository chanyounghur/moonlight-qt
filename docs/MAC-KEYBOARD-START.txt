Moonlight Mac Keyboard v5 — Windows 한영키 영향 수정

기존 Moonlight를 미리 제거하지 마세요.
모든 Moonlight 창을 종료하고 Setup.exe로 업데이트한 뒤 기존 아이콘으로 실행합니다.
연결·페어링 정보는 유지합니다. 설정 파일과 필요한 런타임은 설치 프로그램이 준비합니다.

이번 변경은 Windows 배열 전환 코드를 제거하고 Raw Input을 사용하는 것입니다.
이전 버전 때문에 입력기가 꼬여 있으면 Windows 앱에서 Win+Space로 한국어를 한 번 다시 선택하세요.

확인할 것
- Moonlight 안: 오른쪽 Alt+Space 및 Caps Lock 한영 전환
- 다른 Windows 창: 한영키가 바로 동작하는지
- Moonlight 두 개를 번갈아 사용한 뒤에도 Windows 한영키가 유지되는지

Caps Lock → Control+Space, Alt → Command, Windows → Option,
Super(Menu) → 오른쪽 Command, 마우스 자유 이동은 유지됩니다.
탈출: Ctrl+Alt+Shift+Z
